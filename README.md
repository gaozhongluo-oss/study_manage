# 学习时长记录 · 个人版

一个**纯前端**的个人学习时长记录网页：不登录、不联网、没有后端，双击即用。
数据全部保存在本机浏览器的 localStorage 里，刷新、关闭重开都不会丢。

---

## 一、如何运行

**方式 1：直接双击（最简单，日常够用）**

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。
所有脚本都是普通 `<script>`（不是 ES Module），也没有引用任何 CDN 或外部字体，
所以 `file://` 协议下可以完整运行，断网也能用。

> ⚠️ 两点提示：
> 1. **系统通知**（右下角那条气泡）在 `file://` 下浏览器基本不给权限 —— Chrome/Edge 对本地文件页面的通知权限处理不可靠，详见
>    [Stack Overflow](https://stackoverflow.com/questions/53288572/local-javascript-website-file-confuses-notification-permissions-on-chrome)。
>    想用系统通知请按下面的方式 2 打开（`http://localhost`），页面里也会直接提示这一点。
> 2. **全局浮窗**（番茄计时到点时弹的独立小窗口）需要允许本页弹出窗口。第一次点「开始计时」会自动尝试打开，
>    被拦截时地址栏右侧会提示，允许一次即可（页面也会用 toast 告诉你）。浮窗不依赖通知权限，`file://` 下可用。
>
> 提示音、标签页标题/图标闪烁、任务栏角标在任何方式下都正常工作。

**方式 2：本地静态服务器**（想用系统通知、想在手机 / 平板上访问时推荐）

```powershell
cd study-tracker
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

**方式 3：看示例数据的效果**

```powershell
node tests/make-preview.js     # 生成 tests/preview.html
```
打开 `tests/preview.html` 可以看到填满示例数据的界面。
它使用内存版存储，**不会影响你自己的真实数据**。

## 二、功能与操作说明

### 1. 顶部激励语
- 点击文字直接修改（Enter 保存并退出编辑），改完自动保存。
- 右上角「字号」滑块可实时调整字号（16–56px），同样自动保存。
- 「重置」恢复默认激励语与字号。

### 2. 倒计时
- 点「编辑」修改**名称**和**目标日期时间**，保存后自动持久化。
- 显示剩余「天数 + 时:分:秒」，每秒刷新；到点后会显示「已过去 X 天」。

### 3. 添加学习记录
- 选择项目 → 选日期 → 填时长（小时 + 分，或用 `+15 分 / +30 分 / +1 小时 / +2 小时` 快捷按钮）→ 可写备注 → 保存。
- 保存后会保留项目与日期，方便连着记好几条。
- 下方列表可按「本周 / 全部」筛选，每条记录可 `✎` 编辑、`✕` 删除，并显示筛选范围内的合计。

### 4. 学习项目分类
- 初始 **7 个项目**：5 个学习项目（专业课程 / 编程实践 / 英语提升 / 阅读输入 / 复盘整理）
  \+ **上课** 和 **额外睡眠**（后两个默认**不计入学习时长**）。最多 7 个，也可以更少。
- 每个项目右侧有「**计入**」开关：勾上才算学习时长。上课、额外睡眠默认关闭；
  「额外睡眠」用来记录午睡 / 补觉这类，不污染学习统计。
- 直接改名称、点色块改颜色、切「计入」开关，都是即改即存。
- 删除项目时，该项目下的记录、时间段与番茄记录会自动并入第一个剩余项目，**时长不会凭空消失**。
- 面板底部按项目展示**学习时长**占比条，未计入的项目会单独列在下面（如「未计入学习时长：上课 2小时」）。
- 不计入学习时长的项目**只影响统计口径**：它照样能出现在时间轴上（用它的颜色画块）、照样能用来跑番茄计时。

### 5. 番茄计时器（默认 5 分钟一轮）
- 在「番茄计时」面板先**选择学习项目**（复用你的 5 个项目）；需要的话改「每轮时长」（默认 5 分钟，另有 10 / 15 / 25 / 45）。
- 点「开始计时」→ 大号倒计时 + 进度条实时显示剩余时间，颜色就是所选项目的颜色。
- 一轮结束：自动把这一轮写进当天时间轴，并弹出 **「是否还在学习？」**：
  - 10 秒内点「继续」→ 立即开始下一轮；
  - 不点 / 点「结束」/ 按 `Esc` / 点遮罩 / 点右上角 `✕` → **10 秒后弹窗自动消失，计时结束**。
- 计时中点「停止」：只结算**实际已进行的时长**；不足 5 分钟不写入（时间轴最小粒度就是 5 分钟，避免虚增长度）。
- 写入规则：用所选项目的颜色生成色块；**同项目、时间重叠或首尾相接的色块会自动合并成一个**（时长不重复计算）；
  不同项目的重叠则自动分泳道并排显示，时间轴不会被压坏。
- 边界处理：跨过 24:00 的部分按时间轴范围截断；完全落在 6:00 之前的计时不写入时间轴（会提示，本轮番茄记录仍保留）。
- 刷新或重开不丢：计时中的状态会被恢复——没跑完就接着跑，关页面期间已经跑完的会补写一次时间轴。
- 面板显示「今天已完成 N 轮 · 共 X 分钟」，这份番茄记录（`timerLog`）同样存 localStorage，并随导出一起备份。

**到点提醒：让你在别的软件里也能收到**

一轮结束时，会**同时**用下面这些通道提醒（用得到的都会用，互不依赖）：

| 通道 | 效果 | 说明 |
| --- | --- | --- |
| **全局浮窗** | 一个独立的浏览器小窗口，显示项目 / 轮次 / 倒计时 / 进度条；到点变成红色闪烁的「是否还在学习？」并可以直接点「继续」 | **不依赖通知权限**，`file://` 下可用；只在需要时允许弹出窗口即可 |
| 系统通知 | Windows 右下角气泡 + 通知中心 | 需要授权；`file://` 下浏览器多半不给，改用 `http://localhost` |
| 提示音 | 「叮咚」两声 | 不依赖通知权限，浏览器在后台、窗口被挡住时也能听到 |
| 标签页标题闪烁 | 标题在「⏰ 该确认了！」和原名之间闪 | 浏览器窗口开着但没聚焦时一眼可见 |
| 标签页图标变红 | 换成红色铃铛图标 | 同上 |
| 任务栏角标 | 任务栏图标上出现红点 | 支持 `setAppBadge` 的浏览器（Chrome/Edge on Windows） |
| 页面内弹窗 | 「是否还在学习？」+ 10 秒倒计时 | 回到页面就能点「继续」 |

- 面板上「结束提醒」一行有三个开关：**全局浮窗 / 提示音 / 系统通知**，改完即存；旁边「试一下」可以立刻验证一遍。
- **全局浮窗怎么工作**：点「开始计时」时（在用户手势里，不会被当成恶意弹窗）自动打开一个小窗口；
  到点时主页面会把它 `focus()` 提到最前，所以你切到别的软件也能看到。浮窗和主页面通过同一份
  localStorage + `storage` 事件同步，**在浮窗里点「继续 / 停止 / 结束」主页面会立刻跟上**；计时彻底结束时浮窗会自动关闭。
- **浮窗还会兜底计时**：主页面在后台时，浏览器可能把它的定时器节流到一分钟一次；而可见的浮窗不会被节流，
  所以浮窗发现「已经过了结束时间但状态还是 running」时会先把最新状态读一遍，确认没被主页面结算，才补做结算，
  保证提醒不会迟到、也不会重复写。
- 计时进行中会播放一段约 −60dB 的**无声音频**做保活，进一步降低后台定时器被节流的概率
  （所以计时期间标签页上可能出现音频图标，这是正常现象；它只与「计时中」有关，与提示音开关无关）。
- 通知里会写清楚「项目 + 本轮时长 + 第几轮」；通知设置为常驻，用户处理或 10 秒结束后会自动收起。
- 一旦你回到页面（或点「继续」/「结束」/超时），系统通知、标题闪烁、图标和角标都会立刻恢复原样。

### 6. 夜间睡眠记录（手动输入 + 每晚柱状图）
- **手动录入**：选「入睡当晚」的日期 + 入睡时间 + 起床时间（可写备注），点「保存这一晚」。
  时长自动算，**跨午夜自动处理**（例如 23:30 → 07:00 = 7 小时 30 分；01:00 → 08:30 = 7 小时 30 分）；
  表单上方会实时显示「本晚睡眠 X 小时 Y 分」，起止时间填成一样会提示无法计算并拒绝保存。
- **每晚柱状图**：右侧是当月柱状图，一晚一根柱子，高度即时长；
  深色柱＝睡够 8 小时、浅色柱＝不足 8 小时，红色虚线是 **8 小时参考线**；
  鼠标悬停看当晚的入睡/起床时间、时长、与 8 小时的差距；点柱子即可选中并编辑那一晚。
- **进日历看**：点「📅 日历」→ 切到「🌙 睡眠」→ 有记录的晚上会打上月亮标记 →
  点某一天就直接跳到**那一晚的柱状图**（时间轴日期不受影响，两套入口互不干扰）。
- 面板右上角可以逐月翻看，「本月」一键回到当月；顶部显示本月小结（记录了几晚 / 平均 / 最长）。
- 睡眠是**独立统计**：不参与学习时长、不参与 6 小时目标和周柱状图，只做睡眠自己的账。

### 7. 每日时间轴（6:00 – 24:00）
- **新建**：在轨道空白处按住鼠标左右拖动。
- **移动**：拖动色块本体。
- **改起止**：拖动色块左 / 右边缘。
- **编辑 / 删除**：单击色块，弹出编辑器（可换项目、改时间、加备注、删除）。
  关闭编辑器有四种方式：底部「取消」、右上角「✕」、点弹窗外的灰色遮罩、按 `Esc`；
  关闭不会保存改动（只有点「保存」才写入）。
- 用「画笔图例」选择当前项目颜色，新画的时间段就用这个颜色。
- 同一天内重叠的时间段会自动分成多条泳道并排显示，不会互相遮挡。
- 今天会显示一条红色「现在」竖线。
- 「整周」视图一次看 7 天；点击任意色块会切到那天的「单日」视图并打开编辑器。
- 所有拖动吸附到 5 分钟，超出 6:00–24:00 会自动裁剪。

### 8. 日历：调取任意一天（时间轴 / 睡眠两种用法）
- 时间轴上方一行显示**当前查看的日期**（如「10-08 周四（今天）」）。
- 点「📅 日历」展开月历：`‹` `›` 切月份，「回到今天」一键跳回今天。
- 月历上：**今天**带描边、**选中的日期**为实心高亮、**有记录的日期**显示对应项目颜色的小圆点（最多 3 个）。
- 选中某天 → 时间轴立刻切换到该日并读出当天已记录的内容；切换日期会自动收起日历，
  并关掉正开着的时间段编辑弹窗 —— 不会出现「换了日期弹窗还留着 / 弹窗里改的是另一天」的错乱。
- 原来的原生日期控件（`‹ 日期 ›` + 「回到今天」）也保留着，两种入口互相联动。

### 9. 每周统计柱状图
- 柱状图展示一周 7 天的**总学习时长**，按项目颜色堆叠。**只统计「计入学习时长」的项目**：
  上课 / 额外睡眠不会进柱子、不进 6 小时目标，只在图例下方标注「未计入学习时长：上课 2小时」。
- 红色虚线是 **6 小时参照线**；未达标的部分用半透明虚框标出，柱顶直接写着与 6 小时的差距（如 `−2.5h` / `+1.5h`）。
- 上方显示：周合计、日均（7 天）、达标天数（≥6 小时的天数）、最长一天。
- 鼠标悬停柱子看当天分项目明细；**点击柱子**直接跳到那天的每日时间轴。
- 统计来源可切换：
  - **学习记录**：按手动添加的时长统计（默认）。
  - **时间轴**：按时间轴上色块的实际时间统计（番茄计时的成果也会算进去）。
  - 两种来源分开计算，不会重复计数。

### 10. 数据备份
页脚提供「导出 JSON / 导入 JSON / 清空数据」：
- 导出：下载 `学习时长记录-YYYY-MM-DD.json`，建议定期备份。
- 导入：选择文件后会询问——「确定」= 与现有数据合并（按 id 去重、同名项目自动合并）；「取消」= 用文件覆盖当前数据。
- 清空：恢复初始状态（不可撤销）。

## 三、文件结构

```
study-tracker/
├─ index.html            主页面结构（所有面板）
├─ timer-popup.html      全局浮窗（番茄计时的小窗口，由主页面 window.open 打开）
├─ css/styles.css        主页面样式（含深色模式、响应式）
├─ css/popup.css         全局浮窗样式
├─ js/
│  ├─ util.js            纯工具函数：日期、时长格式化、颜色（可单独测试）
│  ├─ stats.js           纯统计逻辑：每日/每周聚合、泳道分配、色块合并、冲突检测
│  ├─ store.js           数据层：默认值、校验、localStorage 持久化、增删改、番茄计时状态机
│  ├─ chart.js           每周柱状图（手写 SVG，无第三方依赖）
│  ├─ timeline.js        每日时间轴：渲染 + 拖拽交互
│  ├─ calendar.js        迷你月历：调取任意一天的时间轴 / 睡眠
│  ├─ notify.js          到点提醒：系统通知 / 提示音 / 标题图标 / 任务栏角标
│  ├─ popup.js           全局浮窗的逻辑（共用同一份 localStorage + storage 事件同步）
│  └─ app.js             界面逻辑：把上面几块串起来、绑定事件、番茄计时与日历
├─ tests/
│  ├─ stats.test.js      Node 单元测试（逻辑层，不需要浏览器）
│  ├─ make-preview.js    生成带示例数据的 tests/preview.html（含布局自测）
│  └─ make-e2e.js        生成 tests/e2e.html（浏览器交互自测）
└─ README.md
```

分层原则：**util / stats 是纯函数**（不碰 DOM），**store 只管数据**，**chart / timeline / calendar 只管画和交互**，
**app.js 负责连接**。想扩展功能时基本只需要动一个文件。

## 四、数据存在哪里 / 怎么改

- 存储位置：浏览器 `localStorage`，键名 **`study-tracker.state.v1`**。
- 数据结构（导出 JSON 里的 `data` 字段就是它）：

```jsonc
{
  "version": 1,
  "quote":     { "text": "今天多做一点点…", "fontSize": 28 },
  "countdown": { "title": "考研初试", "target": "2026-03-21T08:30" },
  "projects":  [ { "id": "p1", "name": "专业课程", "color": "#4f7cff", "countsAsStudy": true },
                 { "id": "p6", "name": "上课", "color": "#1098ad", "countsAsStudy": false } ],  // 最多 7 个
  "records":   [ { "id": "r1", "projectId": "p1", "date": "2025-12-09",
                   "minutes": 90, "note": "第三章", "createdAt": "…" } ],
  "timeline":  { "2025-12-09": [ { "id": "b1", "projectId": "p1",
                                   "start": 540, "end": 660, "note": "" } ] },
  "timer":     { "projectId": "p1", "durationMin": 5, "status": "running",
                 "round": 2, "roundStart": 1760000000000, "promptUntil": null },
  "timerLog":  [ { "id": "t1", "projectId": "p1", "date": "2025-12-09",
                   "minutes": 5, "startAt": 1760000000000, "endAt": 1760000300000,
                   "createdAt": "…" } ],
  "sleep":     { "2025-12-09": { "bed": 1410, "wake": 420, "duration": 450, "note": "" } },
  "settings":  { "statsSource": "records", "notify": true, "sound": true, "popup": true },
  "ui":        { "tlMode": "day", "tlDate": "2025-12-09", "weekAnchor": "2025-12-09",
                 "recFilter": "week", "recProjectId": null, "tlProjectId": null,
                 "sleepDate": "2025-12-09" }
}
```

说明：
- `date` 一律是本地时区的 `YYYY-MM-DD`。
- `minutes` / `start` / `end` 都是**分钟数**；`start`、`end` 是「从 00:00 起的分钟」，
  例如 `540` = 9:00，`1440` = 24:00，时间轴限定在 `360`（6:00）– `1440`（24:00）。
- `timer.status` 为 `idle` / `running` / `prompt`；`roundStart`、`promptUntil` 是 epoch 毫秒。
  手改数据时若把 `status` 设成 `running`，记得同时给一个合理的 `roundStart`（否则会被当作无效状态重置为 `idle`）。
- `projects[].countsAsStudy` 为 `false` 时该项目不计入学习时长（缺省／旧数据视为 `true`）。
- `sleep` 里每一晚：`bed` / `wake` 是**从 00:00 起的分钟数**（0–1439），`duration` 是自动算出的分钟数
  （跨午夜用 `(wake - bed + 1440) % 1440`）；起止时间相同的记录会被丢弃。

**改数据的三条路：**

1. **界面上改**（推荐）：所有内容都能在页面上直接编辑。
2. **导出 → 改 JSON → 导入**：适合批量整理历史数据。只要 `date` 合法、`projectId` 是已存在的项目 id 即可；
   非法条目会在导入时被自动丢弃，不会让页面崩溃（`store.js` 里的 `normalizeState` 做统一校验）。
3. **浏览器控制台**（F12 → Console）：

```js
// 查看当前全部数据
JSON.parse(localStorage.getItem('study-tracker.state.v1'))

// 备份 / 恢复
copy(localStorage.getItem('study-tracker.state.v1'))         // 备份到剪贴板
localStorage.setItem('study-tracker.state.v1', '粘贴内容')    // 恢复后刷新页面

// 清空重来
localStorage.removeItem('study-tracker.state.v1')
```

> 注意：数据存在**当前浏览器 + 当前打开方式**下。用 `file://` 打开和用 `http://localhost:8000`
> 打开属于不同来源，localStorage 不互通；换浏览器或清理浏览器数据也会丢失。
> 所以重要数据请定期「导出 JSON」备份。

## 五、常用自定义（想改哪里改哪里）

| 想改什么 | 改哪里 |
| --- | --- |
| 每日目标参照线（默认 6 小时） | `js/util.js` 里的 `DAILY_GOAL`（`6 * 60`） |
| 时间轴范围（默认 6:00–24:00） | `js/util.js` 里的 `DAY_START` / `DAY_END`，同时改 `css/styles.css` 里 `--lane-h` 附近的轨道高度与 `timeline.js` 的小时刻度循环 |
| 拖拽吸附粒度（默认 5 分钟） | `js/util.js` 里的 `SNAP` |
| 番茄默认/可选时长、10 秒询问时长 | `js/store.js` 里的 `TIMER_DEFAULT_MINUTES`、`TIMER_PROMPT_MS`，以及 `index.html` 里 `#timerDuration` 的选项 |
| 睡眠参考线（默认 8 小时） | `js/chart.js` 里的 `SLEEP_REF`（`8 * 60`） |
| 睡眠柱子的颜色 | `js/chart.js` 的 `renderSleep()` 里那两个色值（`#5f6caf` 睡够 / `#8a93c9` 不足） |
| 全局浮窗的大小 | `js/app.js` 里的 `POPUP_FEATURES`（`width=372,height=316,…`） |
| 提醒音的音色/次数、闪烁速度 | `js/notify.js` 里的 `chime()`、`setAttention()` |
| 关掉「无声音频保活」 | `js/app.js` 的 `renderTimer()` 里去掉 `Remind.startKeepAlive()`（代价是后台提醒可能迟到） |
| 项目数量上限（默认 7） | `js/store.js` 里的 `MAX_PROJECTS` |
| 初始项目 / 默认激励语 | `js/store.js` 里的 `DEFAULT_PROJECTS` / `DEFAULT_QUOTE`（含哪些项目默认不计入学习时长） |
| 新增项目时的候选颜色 | `js/store.js` 里的 `COLOR_PALETTE` |
| 一周从周日算起 | `js/store.js`、`js/app.js` 中 `U.weekDates(date, 1)` 的第二个参数改成 `0` |
| 想换成 ECharts / Chart.js | 只替换 `js/chart.js`，保持 `renderWeekly(host, model)` 这个入口不变即可（模型里有 `state` 与 `weekStats` 结果） |

> 关于图表库：需求里允许使用 ECharts / Chart.js，但两者都需要联网或额外引入文件。
> 为了满足「本地运行、无需联网、双击即用」，这里用原生 SVG 手写了一个等价的柱状图
> （堆叠柱 + 6 小时参照线 + 悬停明细 + 点击联动），零依赖、体积小。
